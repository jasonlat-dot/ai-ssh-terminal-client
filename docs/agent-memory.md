# 长期记忆

对话顶部的“记忆”打开管理窗口。空白对话、未配置模型时仍能管理全局记忆，无需新建会话或发送模型请求。

- 列表支持标题、内容和服务器搜索，以及全部范围、当前对话适用、全局和具体服务器项目筛选；类型、启用状态可叠加筛选并一键清除。筛选仅影响管理窗口，不切换聊天或 SSH 连接。
- 弹窗高度固定在视口内，搜索、筛选和分页栏保持可见；仅列表内部滚动，每页 8 条。紧凑列表默认显示一行内容，点击标题可展开完整内容，空结果会提示调整筛选。
- 支持新建、编辑、删除和列表快捷启停。偏好与经验由用户填写并确认，模型不会自动保存。
- 删除记忆使用独立确认弹窗，展示名称、范围和删除影响；默认聚焦取消，失败时保留弹窗并显示原因。新增、编辑和删除成功后显示操作结果提示，取消确认不重置原列表位置或筛选。
- 启停后用保存结果原位更新该条记录，不重新拉取列表、不把记录置顶，也不主动重置筛选、页码、展开状态或滚动位置；等待期间只锁定当前记录。完整数据同步通过“刷新”手动触发。
- 从普通对话打开也能编辑其他服务器项目的记忆：前端根据记录完整目标身份匹配所属项目，提交项目上下文，由原生侧验证用户归属与服务器身份，无需先切换到该服务器聊天。项目已移除或身份变化时不会强行修改旧服务器记录，仍可删除自己的记录。
- 编辑表单仅保留一个“生效范围”，可选择全局或已确认身份的服务器项目；未筛选时默认当前对话环境，已筛选具体项目时默认该项目。尚未确认身份的项目默认全局，不会错误选中另一服务器。已有服务器记录只允许保留原服务器或改为全局，后者仍用原项目上下文验证。
- 保存和删除使用记录版本；发生冲突时保留编辑文字，刷新并核对最新版本后可再次保存。失败不改变已经确认的启用状态，连续点击不会重复提交。
- 标题最多 120 UTF-8 字节，内容最多 2048 字节；中文通常占 3 字节。每个用户最多保存 128 条。
- “启用这条记忆”保存后生效。关闭时保留记录、暂停供后续消息参考；实际使用受生效范围和上下文容量限制。不会改写已有请求、聊天内容或工具审批权限。
- 列表在标题同排展示“全局生效”或“项目名 · 主机:端口”标签，并展示类型、服务器范围、更新时间和启用状态；编辑、删除与启停开关位于标题同排，具有悬停、键盘聚焦和禁用反馈。

持久化、归属核对与版本校验沿用原生 `agent/memories` 接口，详见 [agent-ipc.md](agent-ipc.md)。

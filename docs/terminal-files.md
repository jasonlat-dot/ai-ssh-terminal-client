# 左侧终端文件浏览

适用于 **v0.2.5**，发布说明见 [v0.2.5](releases/v0.2.5.md)。

工作区侧栏顶部可在“会话”和“文件”之间切换。“会话”保留原来的对话历史与 SSH 连接列表；“文件”浏览当前激活 SSH 终端对应服务器的目录。分屏时跟随激活的终端，不按对话模型或其他窗格猜测服务器。

- **跟随终端目录**默认开启。新建或重连 SSH 时复用会话级 Bash 集成，在提示符返回时同步当前目录；同目录执行命令后也刷新文件列表。目录列表可见时每次读取完成 5 秒后更新，隐藏到托盘、打开设置、切换侧栏或断线时停止请求。
- 点击目录、上一级或提交绝对路径会进入自由浏览，自动关闭跟随；不会向 Shell 发送 `cd`、`pwd` 或 `ls`。重新勾选跟随后立即回到最近上报的终端目录。
- 支持隐藏文件开关、手动刷新、文件选择与路径复制。“管理与传输”打开原有完整文件管理器，保留上传、下载和其他已有操作。
- 目录变化的监听独立于终端焦点和 AI 补全。目录清单及文件内容不发给模型；仅开启目录跟随不会开启智能补全或 AI 续写。

## 接入范围

自动跟随复用 Bash 4.4+ emacs 模式集成，只作用于当前 Shell，不修改 `.bashrc` 或创建远端脚本文件。关闭补全和目录跟随后，新连接不安装这份集成；已经安装的会话钩子保留到 Shell 退出。自定义启动命令继续跳过自动安装，避免向 sudo、跳板或正在运行的程序注入载荷。

已有终端需要重新连接才能加载新目录上报钩子。未接入的 Shell 先显示 SSH 登录账号的 SFTP 家目录，并明确提示可手动浏览，不把登录目录冒充当前 Shell 位置。命令运行中显示上次同步位置，等待下一次提示符；任意子 Shell、tmux 或二次 SSH 没有有效上报时不猜路径。普通目录浏览使用原 SSH 登录账号，已接入的 sudo Bash 可复用终端 root 认证；不浏览二次 SSH 登录的其他服务器。本地 CMD 显示说明，不提供远程文件清单。

### sudo 登录目录跟随

在已接入的 Bash 中执行无其他参数的 `sudo -i` 或 `sudo --login`，会话级包装保留 sudo 自身的认证过程，将集成接入目标 Bash。由 sudo 准备目标登录环境，新交互 Bash 先读取目标 `.bashrc`，再安装目录与补全钩子。载荷通过目标进程创建的临时文件描述符传递，不修改启动文件、不写远端脚本、不向密码提示符或运行中的程序发送安装命令。退出后父 Shell 原来的钩子继续工作。

sudo 登录模式会将参数重新拼为 Shell 命令，同时保留 `$` 的展开行为（见 [sudo 参数处理源码](https://github.com/sudo-project/sudo/blob/main/src/parse_args.c)）。因此仅使用 Bash `%q` 不能保护整个脚本；载荷先编码为十六进制转义，传递给 sudo 的启动命令不包含变量或命令替换，到目标 Bash 内才解码。避免 `$BASH_VERSION`、`$-`、`$PWD` 等在接入前被错误替换。

普通 sudo 命令及附带其他参数的调用原样透传，退出码不变；已有 sudo 函数/别名保留，不覆盖。目标登录 Shell 不是 Bash 时执行该 Shell 的普通登录流程，不强行接入。自定义 Bash 启动逻辑需实际验收；此接入使用登录环境中的交互 Bash，不模拟任意登录 Shell 的全部启动与退出行为。

**左侧目录浏览复用这一次终端 sudo 认证。** 原 SFTP 通道本身不提权；已进入 root 的交互 Bash 启动只读目录元数据通道，后台仍通过原 SSH transport 发送固定读取请求，不再运行 sudo、不索取第二次密码。支持跟随目录与自由浏览，长命令执行期间不向 PTY 注入命令。退出 root 恢复登录账号；嵌套 sudo、其他终端、重连均使用各自身份与通道，旧身份的缓存和在途结果清除。

该通道需要 Linux Bash、GNU find/timeout 及命名管道，不依赖 Python 或远端 agent。不修改 `.bashrc`、sudo 配置或账号权限。临时目录由 root 拥有且不可被普通账号改写；只有原登录 UID 可写请求 FIFO。目录请求仅接受固定读目录/回收请求、32 位随机请求 ID 和十六进制路径；不执行传入命令，元数据不上传模型。目录响应最多约 1 MiB、最多展示 4096 项，未领取元数据最多保留 15 秒、最多 32 份，父 root Shell 退出后清理。当前用户的其他进程属于同一 Unix UID 权限范围。

### 文件管理入口与当前终端目录

终端工具栏“文件 · SFTP”和侧栏“管理与传输”调用同一个入口，按当前终端标签页创建文件窗口。打开时读取该终端最近上报的目录与身份，自动连接并定位到此目录；普通账号使用原 SSH transport 的 SFTP，已提权终端使用 root Shell 中固定的 OpenSSH `sftp-server` 通道，复用这次认证，无需再次 sudo 或输入密码。需要服务器已有独立的 OpenSSH `sftp-server` 可执行文件，不自动安装。

文件管理把“初始位置”与“可浏览根范围”分开：已知当前目录时根范围默认为 `/`，打开后定位到当前目录，可继续向上或进入其他有权限的位置，不把当前目录变成新的浏览边界。没有有效目录上报时才回到该身份的 SFTP 默认目录。重新打开同一终端的文件窗口会再次定位最新目录；同一服务器的多个终端窗口互不串目录。文件窗口打开后可自由浏览，不在每次提示符返回时抢走位置。

root 二进制通道仍由 root 拥有的临时 FIFO 转发，仅启动固定路径的 `sftp-server`，最多 4 条流、未接入 10 秒回收，文件会话失效或关闭通道时回收。退出 root、切换身份、重新接入 nonce 或关闭终端会撤销已绑定的文件会话及传输；关闭文件弹窗只隐藏窗口，保留后台传输，退出应用时释放文件通道。正在进行传输时再次从入口打开，保留现有会话和位置并提示，避免重新连接打断任务。操作的正文通过现有 SFTP 传输，不进入模型请求。

连接表单默认“当前终端身份”，原来的独立“SSH 登录账号”和“root（通过 sudo）”入口仍可手动选择。应用不截取、保存或重放终端输入的 sudo 密码。

手动限定远程根目录时，仅在终端当前目录位于该范围内才定位到它，否则打开所选根目录。初始目录加载过程中若终端身份失效，不提示连接成功；旧文件会话迟到的目录错误也不会使新会话失效。

开发版开启 React StrictMode 时，首次自动连接会经历 effect 清理与立即重放。文件管理在一个微任务后确认真正卸载再撤销请求，避免把仍挂载窗口的首次连接标记过期、导致永久停留在“连接中”。真正卸载仍会释放已建立的会话，迟到完成的连接也会关闭。

进入或退出 root 时，旧文件会话通过 `SFTP_IDENTITY_CHANGED` 正常撤销，静默清空旧列表与权限，不弹全局错误。重新打开文件管理即可使用当前身份；目录请求、进度事件及在途操作使用同一状态。文件确实不存在、无权读取和异常断线等错误仍正常提示。

主动关闭终端时，其绑定文件会话通过 `SFTP_TERMINAL_CLOSED` 正常结束，不提示“连接、会话、任务或文件不存在”。该原因贯穿目录操作、进度订阅及原生层已在途的请求；按终端会话而非 SSH 连接配置判定。同一 SSH 连接的其他终端和文件会话保持可用，连续关闭多个标签页也各自独立清理；异常断线和真正缺失的文件仍按错误处理。

## 生命周期与边界

### 拖入 SSH 终端上传

把系统文件或文件夹拖到已连接的 SSH 终端正文区域，会先显示投放提示，再弹出“是否上传到以下目录”的确认框，列出服务器、当前目录与本地条目。取消不创建文件会话、不发起上传。支持多文件、文件夹和分屏；按实际投放窗格选择服务器，原生物理坐标转换为 CSS 坐标后命中检测，其他弹窗覆盖终端时不会误收投放。

Windows 系统拖入复用 Tauri/WebView2 自带的文件拖放事件，无需提前点击终端获取输入焦点。支持实际存在的本地文件和文件夹；从压缩包内部拖出的虚拟条目需先解压，不把虚拟显示名称当作本地路径。不再重复注册 OLE 接收目标或维持自定义 COM 文件数据解析器。

文件管理器内部双向拖动使用指针事件，避免与原生 OLE 接收冲突。左侧拖到右侧上传，右侧拖到左侧下载，目标卡片显示“在此区域松开鼠标即可上传／下载”和目标路径。松开后复用原传输接口与队列；路径变化、连接或身份失效、窗口隐藏、Esc 取消及失焦都会终止在途拖动。下载默认遇到同名文件停止，保留本地原文件。顶部保留访问账号切换，删除操作显示为红色文字并继续使用原有确认流程。

确认前重新核对原终端 session、身份和目录；重连、sudo 切换或目录变化要求重新拖入确认。目录尚未同步或命令仍在运行时不猜测上传目标。本地 CMD / PowerShell 不作为 SSH 上传目标。确认后目标路径固定，随后在终端中 cd 不会改变已批准的上传位置；身份撤销或断线会停止尚未提交的文件。

确认后打开同一终端的文件管理及传输队列，复用现有 `useSftp` 与原生上传任务；普通身份或已认证 root 使用同一文件通道。兼容的已开窗口直接复用并保留任务记录；其他身份有传输进行时等待完成后再连接，不打断旧传输。重复 effect 不重复提交，同一终端连续确认的投放按顺序处理。任务进度、成功、失败与重试仍显示在原传输队列；关闭弹窗可继续后台传输。结束文件会话或关闭应用后不会额外持久化记录。

终端拖入上传固定使用“同名停止、保留服务器原文件”策略，与确认框说明一致，不继承之前在文件管理中选择的替换策略。

`RemoteTerminal` 解析私有 nonce 绑定的 OSC 目录消息，支持分包、Unicode 和提示符重装后的 nonce 更新。终端切换/重连使用各自运行时；旧目录请求取消，迟到结果不会覆盖新目录或其他服务器。

原生 IPC `GET ssh/terminal/directory` 固定绑定原终端和工作区。普通身份使用只读 SFTP 元数据接口；终端已提权时，仅使用后台从该终端私有 nonce 报告中确认的 root 通道，不接受前端提供任意通道路径。后台重查身份 revision，切换后不返回旧提权结果；通道故障明确报错，不静默回退或重新认证。请求总期限 5 秒，原终端不因浏览失败而断开。

本功能包含 Rust/Tauri 原生变更，需要完全退出托盘后重新运行 `npm run tauri dev`，然后重连 SSH。保持现有主题、壁纸、小窗口与侧栏宽度设置；没有新增数据库迁移或修改版本号。

# 网络代理

入口：设置左侧“其他设置”（位于“关于与更新”上方）。终端智能补全配置也移到此页，模型页只显示模型配置。

大模型请求、SSH 与文件传输分别选择连接方式，并点击“保存代理设置”：

- 直接连接：忽略应用层代理环境变量和 Windows 静态代理。
- 使用本机代理：优先读取进程的 `HTTP_PROXY` / `HTTPS_PROXY` / `ALL_PROXY`（支持小写），其次读取当前 Windows 用户的系统静态代理；遵循 `NO_PROXY` 和 Windows 代理排除项。没有代理配置时直连。修改环境变量后需重启程序才能继承新值。SSH 优先使用 HTTPS/ALL，然后 HTTP 环境变量，静态配置优先 HTTPS、HTTP、SOCKS。
- 自定义代理：填写 HTTP/CONNECT 或 SOCKS5 的主机与端口。主机不包含协议、路径或端口；IPv6 可填地址。代理用户名和密码可选。

模型代理覆盖聊天、AI 续写、上下文整理和模型列表请求。SSH 代理覆盖新建终端及独立文件会话；绑定终端的文件会话复用该终端的网络连接。SOCKS5 使用代理侧 DNS，HTTP 代理通过 CONNECT 转发 SSH；SSH 密钥验证和登录认证仍由 SSH 协议执行。

两组代理各自有“直连白名单”，每行一条，也可用中英文逗号或分号分隔。支持 `192.168.1.10`、`192.168.1.10:22`、`api.example.com`、`api.example.com:443`、`*.example.com`、`[2001:db8::1]:22`。不填端口表示全部端口；填写端口时只匹配该端口，HTTP/HTTPS 省略端口按 80/443 匹配。精确域名只匹配自身，`*.example.com` 只匹配子域名，不含根域名。匹配忽略域名大小写并规范化 IPv6；自动移除空条目和重复项，每组最多 256 条。

白名单对“使用本机代理”和“自定义代理”均生效，并优先于代理检测。匹配目标地址本身，不额外将域名解析为 IP 进行匹配；IP 条目仅用于以该 IP 为目标的请求。非法规则会拒绝整次保存并保留原配置。旧配置没有白名单时按空列表加载。

初始设置为模型使用本机代理、SSH 直接连接。此前 SSH 使用直接 TCP，不会因为开启 Windows HTTP/SOCKS 代理而自动使用它；模型主要受进程代理环境变量影响。TUN/VPN 等操作系统路由仍由系统决定，本设置不修改它。

`localhost`、IPv4 回环地址和 `::1` 始终直连，以便访问本机 Ollama、WSL SSH 等服务。代理设置保存后用于后续模型请求和新建 SSH 连接；已建立的终端、文件传输和进行中的请求继续使用原路径。代理不可用或认证失败会报错，不自动切换直连。

“使用本机代理”支持静态 HTTP、SOCKS5 地址，不执行 PAC/WPAD 自动发现脚本。仅配置 PAC 时会提示改填自定义代理；可填写代理软件提供的本机监听地址和端口。HTTPS 代理端点、系统集成认证不在当前支持范围。

代理配置存于当前工作区 SQLite，整体经 Windows DPAPI 加密。界面只返回密码是否已保存，不返回密码正文；密码留空保留旧值，勾选“清除已保存的密码”才删除。诊断不记录代理认证信息。

验证使用临时数据库、回环模拟代理和 SSH/SFTP 服务器：覆盖 HTTP CONNECT、SOCKS5 用户名密码认证、代理侧域名解析、认证失败、本机地址绕过、加密保存、密码保留/清除、SSH 连接复用及更换代理后不复用旧连接。未使用真实模型密钥或修改本机代理设置。

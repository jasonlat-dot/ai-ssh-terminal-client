# ShellPilot v0.2.5

本次更新新增终端目录跟随、终端拖入上传和双向拖拽传输，文件浏览可复用当前终端的 sudo 认证；设置中增加网络代理与直连白名单，并统一补全模型选择体验。

## 终端目录与文件浏览

- 工作区侧栏新增“会话 / 文件”切换，文件栏跟随当前激活的 SSH 终端；同一服务器的多个终端分别使用各自的目录和身份。
- 默认跟随终端当前目录，支持目录导航、隐藏文件、手动刷新和路径复制。手动进入其他目录时关闭跟随，重新勾选即可回到终端目录。
- 目录变化和命令结束后刷新文件列表；文件栏可见时定时更新，隐藏、离开工作区或断线时暂停。没有有效目录报告时明确显示登录账号的默认目录，不猜测 Shell 位置。
- 已接入的 Bash 执行 `sudo -i` 或 `sudo --login` 后可同步 root 目录；目录浏览与文件管理复用这一次终端认证，不再次索取密码，也不截取、保存或重放 sudo 密码。
- 终端工具栏“文件 · SFTP”和侧栏“管理与传输”使用同一入口，默认采用当前终端身份并定位当前目录。文件窗口打开后可自由浏览，正在传输时保留原会话与位置。

## 拖拽上传与下载

- 将系统文件或文件夹拖入已连接的 SSH 终端，先显示投放提示，再确认服务器、目标目录和待上传条目；确认后上传到该终端目录，并在现有传输队列中查看进度与结果。
- 支持多个条目及分屏，按实际投放终端选择目标；取消确认不会创建上传任务，终端或身份失效后不会向旧目标继续上传。
- 文件管理支持本地向远程拖拽上传、远程向本地拖拽下载，目标区域显示“松开即可上传 / 下载”及路径提示，沿用现有同名文件处理与传输队列。
- 移除文件窗口中的“结束文件会话”按钮，删除操作改为红色文字并保留确认；修复文件列表底部悬停跳动。
- 系统拖入使用 Tauri 原生文件事件。压缩包内尚未解压的虚拟条目需先解压为普通文件，再进行拖入。

## 其他设置与终端补全

- 左侧新增“其他设置”，位于“关于与更新”上方；终端补全配置移入此页，模型页只显示模型渠道。
- 补全设置采用紧凑布局，接入方法和说明默认折叠；总开关、AI 续写、目录发送及触发延迟状态更明确，关闭总开关仍保留原有选择。
- AI 续写复用对话的“供应商 / 渠道 → 模型”两级选择器，保持品牌图标和键盘操作一致；补全模型单独保存，不改变对话模型，已有选择可继续使用。
- 完善 sudo 子 Shell 接入、退出后的序号恢复及补全状态同步，自动接入不再重复弹出初始化成功提示。
- 补全设置、代理白名单及终端演示面板适配主题和壁纸透明效果，保留原有动效。

## 网络代理与直连白名单

- 大模型请求和 SSH / 文件传输分别支持“直接连接”“使用本机代理”“自定义代理”。自定义代理支持 HTTP / CONNECT、SOCKS5 及可选账号密码。
- 本机代理优先读取进程代理环境变量，其次读取 Windows 系统静态代理；没有配置时直连。PAC 自动配置脚本暂不执行，可填写代理软件提供的本机地址和端口。
- 两组连接分别配置直连白名单，支持 IP、精确域名、`地址:端口`、`*.example.com` 及 `[IPv6]:端口`。省略端口匹配全部端口，命中后直接连接；支持逐行输入、逗号分隔、自动去重及格式校验。
- 代理配置经 Windows DPAPI 加密保存，界面不返回已存密码。模型请求、AI 续写、上下文整理和模型列表使用模型代理；新 SSH 连接与独立文件会话使用 SSH 代理，绑定终端的文件会话复用原连接路径。
- 本机回环地址始终直连。保存设置后用于后续请求和新连接，已有终端与进行中的请求保持原路径；代理失败不会自动退回直连。

## 连接与会话修复

- 重连进度与结果使用同一条通知更新，避免“正在连接”和“已连接”同时残留。
- 修复开发模式首次打开文件管理可能一直停留在“连接中”的问题，避免旧请求覆盖新会话状态。
- 进入或退出 root、主动关闭终端时，关联文件会话正常清理，不再误报“连接、会话、任务或文件不存在”。同一 SSH 连接的其他终端保持可用，真实文件错误和异常断线仍正常提示。

## 升级与发布

- 客户端与 Rust 业务库同步为 **0.2.5**。沿用现有应用标识、数据目录、更新通道与签名公钥，新增 `025_network_settings.sql`，启动时创建加密网络配置表；已有连接、模型、历史和附件继续保留。
- 安装前等待任务和传输结束，从托盘完全退出并备份实际工作区。开发环境需重新编译原生程序；已有 SSH 会话需重连，才能加载新的 Bash 目录跟随集成。

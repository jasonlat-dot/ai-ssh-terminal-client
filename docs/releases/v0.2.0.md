# ShellPilot v0.2.0

本次更新完善智能对话与终端协作，加入扩展工具、长期记忆和更灵活的桌面布局，并优化启动与日常操作体验。

## 智能对话与工具协作

- 支持普通对话与绑定 SSH 服务器的任务对话；服务器任务保留明确的连接目标。
- 支持模型委派子任务，独立任务可并行推进，可查看执行过程与结果。
- 工具统一遵循当前对话的审批边界，覆盖 SSH、MCP 与其他已注册工具；普通对话不注册 SSH 工具。
- 支持 MCP JSON 配置、语法高亮与启用开关，兼容 Streamable HTTP、旧版 SSE 和本地 stdio。
- 支持配置 Skills 目录，按需读取 SKILL.md 和参考文件。
- 执行额度支持前端配置与常用档位选择，输出分页回查不占工具调用次数。
- 推理强度移至对话输入区，模型请求参数支持预设选择。

## 记忆与上下文

- 新增长期记忆管理，支持全局及服务器范围、筛选、编辑、启停与删除。
- 区分长期记忆和当前任务上下文；记忆不会自动授予工具执行权限。
- 优化长对话整理、无效摘要的拒绝原因反馈与重试处理。
- 支持图片、文本及可提取文字的 PDF 附件。

## 终端与 SFTP

- 支持本地 CMD、SSH 多会话、终端分屏及页签排序。
- SFTP 提供 SSH 登录身份与 sudo root 访问方式，并说明文件连接与终端身份之间的关系。
- 优化 Agent、SSH 连接列表和常用命令的收起、展开及入口提示。

## 界面与交互

- 全新线条与粒子动效启动页，至少展示 2 秒，服务就绪后淡出并进入工作区。
- 将协作演示移到空终端欢迎页，适配浅色与深色主题；精简装饰、功能卡片及多余留白。
- 对话空态改为线条对话图形与柔和动效，引导文案按普通对话或服务器任务轮换；离开可见区域暂停，减少动态效果模式保持静态。
- 窗口最小尺寸降低至 360 × 320，窄窗口提供对话与终端切换，连接侧栏改为浮层。
- 保存、删除等操作提供统一提示，关键删除操作增加确认。
- 优化导航图标、悬停解释、参数布局及配置弹窗。
- 统一主要设置分组、工具审批和弹窗标题的彩色图标高亮，沿用模型配置的图标与明暗主题参数。
- 收紧本地工作区设置，统一存储参数预设和开关样式，修复壁纸模式下的实心会话列表与整行提示底色。
- 应用名称、界面版本和客户端版本元数据统一为 ShellPilot v0.2.0。
- 恢复侧边栏“关于与更新”入口，接通版本信息、检查更新、下载与确认安装，以及启动更新提示的跳转。
- 沿用旧版 GitHub Releases 更新通道与现有签名公钥，正式安装版从同一 latest.json 获取更新；开发模式不执行更新。

## 使用说明

- Rust 后端随桌面程序内置，无需额外安装 Java / JRE。
- MCP、Skills 和模型服务需根据实际环境配置；推理强度等参数取决于供应商支持。
- SFTP 的 sudo root 访问需服务器允许 sudo 并提供可用的 sftp-server；终端切换用户不会自动改变独立文件连接的身份。
- 扫描 PDF / OCR、Office 文档解析及旧版本数据自动导入暂未提供。

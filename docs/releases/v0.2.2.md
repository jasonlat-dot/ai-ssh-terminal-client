# ShellPilot v0.2.2

本次更新支持一个渠道配置多个模型，完善多协议工具续聊、失败排查和终端交互。桌面版继续使用内置 Rust 后端，无需 Java 或独立后端服务。

## 模型配置与切换

- 同一供应商 / 渠道可配置多个模型 ID，共用接口地址、API Key 和公共参数；对话中按渠道选择模型。
- 渠道与模型统一展示兼容协议的 OpenAI / Claude 图标，输入框仅显示图标和模型 ID。双栏菜单在输入区居中位置略向右调整，窄区域保持单栏居中，随窗口和聊天分栏宽度调整并避让边界。
- 配置弹窗将渠道名称与推理强度放在同一行，下方依次配置 Base URL、API Key 和模型 ID。
- 支持 Anthropic Messages 原生接口，以及 Chat Completions、Responses。按协议保存和回传 DeepSeek 推理内容、Gemini 工具签名、Claude 思考块及 Responses 原生输出，改善工具调用后的续聊兼容性。
- Claude 推理强度提供默认、低、中、高、很高、最高；默认不额外发送强度参数。具体档位仍须模型和代理支持，最大输出同时约束思考与正文。
- 空闲时可在当前会话切换模型，保留聊天、项目、SSH 目标与审批策略；运行中的请求或工具执行会阻止切换。

## 对话与工具输出

- 失败回复在对话内保留错误信息、Trace ID、“定位日志”和“恢复到输入框”，减少输入框上方重复展示。恢复内容后由用户决定是否发送，不自动重试或重复执行命令。
- 修复历史会话切换状态问题，保留失败请求和已有执行证据。
- 隐藏正常的工具输出回查条目与次数，回查失败仍显示提示。
- 展开命令直接加载已保存的完整输出；“复制输出”复制执行文本，不再复制 JSON 传输外壳。输出已过期、读取失败或达到捕获上限时明确提示。
- 翻看历史且未在底部时显示返回按钮，生成中显示三点，悬停切换箭头，点击回到最新回复并恢复跟随；修复按下时的横向跳动。

## 日志与终端

- 按日期和 Trace ID 保存请求诊断日志：`logs/agent/YYYY-MM-DD/<traceId>.log`。内容为逐行 JSON，记录请求过程和用户 / 助手正文，便于关联排错。
- 默认日志级别 INFO、保留 7 天；支持调整级别和保留时间，过期请求日志自动清理。失败卡片可在文件管理器中定位对应 `.log`。
- 修复 Windows 调试运行中发送消息可能触发的栈溢出。
- 修正 Agent 面板开关高亮；终端选中文字时 Ctrl+C 复制，无选区时保留中断行为。
- 统一“添加到对话”的悬浮提示，选区浮动按钮优先显示在所选内容上方，并避让窗口边界。

## 升级说明

- 从 v0.2.1 覆盖升级，沿用 `com.jasonlat.shellpilot` 应用标识、现有数据目录和更新签名公钥。
- 首次启动自动将 SQLite 升级至 schema 24；已有单模型配置保留原 ID，可继续使用，编辑后可增加渠道内模型。
- 升级前从托盘完全退出并备份实际工作区。数据库迁移后若需回退，应恢复升级前的完整备份，不直接用旧程序打开升级后的数据库。
- 本地日志包含对话明文，分享前请脱敏。旧版本已经丢弃的思考字段无法通过升级补回；旧 Java 数据仍不自动导入。

详细步骤及发布验收见 [v0.2.2 升级与发布](v0.2.2-upgrade.md)。

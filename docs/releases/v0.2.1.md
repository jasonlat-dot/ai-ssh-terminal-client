# ShellPilot v0.2.1

本次更新完善托盘、窗口缩放与 SSH 新手引导，增加主动上下文压缩，并统一正式版名称与数据目录。

## 桌面体验

- 关闭窗口或按 Alt+F4 隐藏到托盘，终端、文件传输和智能体任务继续运行；托盘右键“退出”完全关闭应用。
- 采用单实例运行，再次点击任务栏固定图标、开始菜单或快捷方式会恢复已有窗口。
- 扩大窗口四角与边缘的缩放感应区，右上角避开关闭按钮；最大化和全屏时禁用自定义缩放区。
- Windows 主程序统一为 `ShellPilot.exe`，安装或更新时补建缺失的开始菜单入口。

## SSH 新手指引

- “查看连接指引”改为三步操作流程：保存 SSH 连接 → 创建并绑定服务器项目 → 新建项目对话。
- 可以复用已有连接和项目；保存配置后返回引导继续，缺少模型时可前往设置再返回。
- 完成后提供示例任务，仅填入输入框，由用户确认发送。

## 模型与上下文

- 新建模型默认上下文窗口 256000、最大输出 2048、安全预留 8192、自动整理阈值 75%、超时 120 秒、最大响应 1 MiB，Temperature 默认不发送；已有显式配置保留。
- 上下文详情卡片新增“立即压缩上下文”，可在空闲时整理已保存的历史，显示压缩状态并支持取消。
- 主动压缩复用当前会话模型，仅生成历史检查点，不新增用户消息、不执行工具、不删除原始历史。
- 工具批次执行结束后、下一次模型请求之前仍会检查阈值并按需自动整理；不会打断执行中的命令。
- Responses 协议需要供应商支持并启用远端整理；失败和取消不会伪报成功，原始历史保留。

## 正式工作区与升级

- 首次启动在创建 WebView 前复制旧预览版工作区，包括数据库、附件、配置和 WebView 持久数据；保留旧目录作为备份，不覆盖已初始化的正式工作区。
- 旧应用根目录内的数据路径同步迁移，外部自定义数据目录保持原位置。若复制失败或目录冲突，明确报错，避免加载部分数据。
- 更新前请从托盘完全退出旧版。旧 Java 数据不在本次自动迁移范围内。

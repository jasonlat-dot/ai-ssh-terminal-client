# ShellPilot v0.2.3

本次更新新增 Google Gemini、DeepSeek、GLM / 智谱和 Qwen / 通义千问供应商入口，完善模型查询与渠道管理，并优化终端操作、工具输出回读和设置界面。

## 模型供应商与配置

- 新增 Google Gemini GenerateContent 原生协议，支持文字、图片、流式回复、工具调用、思考签名续接及本地上下文整理；原有 OpenAI 兼容入口仍可继续使用。
- DeepSeek、GLM / 智谱、Qwen / 通义千问提供独立供应商选项和品牌图标，支持 Chat Completions 与 Messages。各供应商分别处理思考开关、推理强度、输出参数和工具续聊，不按模型名称硬编码。
- Qwen 统一通过流式传输收集回复、工具规划与摘要，适配只接受流式思考请求的模型；增加独立“开启思考”选项，不强制附加推理档位。
- 基础地址留空时使用对应供应商及协议的默认地址，显式填写的地域、业务空间或代理地址保留。已有兼容渠道不会自动转换供应商，需在编辑配置时自行选择。
- 模型 ID 区增加“查询上游模型”，支持搜索、逐项添加、移除和全部添加；编辑时可复用已保存的 API Key，查询不保存草稿。目录不可用时保留手动配置和原有选择，失败提示附带 Trace ID。
- 模型列表不代表上游保证支持图片、工具或所选推理强度；具体能力以实际模型和接口为准。GLM 端点可能不提供模型目录，此时可直接手动填写 ID。

## 渠道管理与更新说明

- 配置卡片按创建先后排列，编辑和改名不改变位置；宽窗口按可用空间增加列数，窄窗口自动换行。
- 支持供应商筛选与渠道名称搜索，两项按“并且”匹配，匹配数量紧随搜索框显示。
- 增加置顶与取消置顶：最近置顶的渠道排在最前，取消后恢复创建顺序；置顶偏好保存在本机，不绕过筛选条件。
- “关于与更新”使用 Markdown 展示当前版本和待更新版本的说明。升级后当前版本说明仍可查看，离线或检查失败也不影响阅读。
- 正式版首次运行未读版本时展示“本次更新内容”，关闭后记录已读状态，之后可在设置中查看。

## 终端与工具输出

- 将终端复制、粘贴、字号和连接操作收纳到顶部“终端”菜单，操作跟随当前终端；无选区时 Ctrl+C 仍用于中断。
- 断线终端支持按键发起重连；SSH 连接等待提示随成功、失败、超时或取消及时结束，避免迟到连接残留。
- 模型读取工具输出时，默认每次 4 KiB，单次最多 16 KiB。省略读取量时自动使用默认值，超限正整数限制到上限，主任务与子任务规则一致。
- 输出按 nextOffset / eof 继续读取，不重新执行原命令；回读不占工具执行次数，后续模型请求仍计入轮数，并受上下文容量限制。
- 界面展开完整输出与模型回读分别分页；原始输出捕获上限不变，已过期或未保存的内容不能通过回读补回。

## 界面优化

- 本地工作区左侧排列半宽运行状态与启动目录，附件存储上移至右侧顶部，减少留白；窄窗口自动切换单列。
- 主操作与保存按钮统一为浅蓝底、深蓝文字，初始化与停止按钮增加颜色区分和悬停反馈。
- 开关采用柔和蓝色，同步适配深色主题和壁纸模式。

## 升级与发布

- 从 v0.2.2 覆盖升级，沿用应用标识、数据目录、更新通道和签名公钥；数据库仍为 schema 24，本版本不新增迁移。配置、历史和附件继续保留。
- 安装前等待回复、命令和传输结束，从托盘完全退出应用并备份实际工作区；自定义数据目录也需备份。开发环境需重新编译桌面原生代码，仅刷新网页不会更新后端。
- 两个仓库使用匹配的 0.2.3 源码，保持平级目录；在客户端目录配置原有签名环境变量后执行：

```powershell
npm ci
npm run release:windows -- --notes docs/releases/v0.2.3.md
```

产物位于 `release/v0.2.3/`：`ShellPilot_0.2.3_x64-setup.exe`、对应 `.sig`、`latest.json`、`SHA256SUMS` 和 `release-notes.md`。脚本不会自动提交、打标签或上传；正式发布使用匹配的安装包和签名。

发布前使用实际安装包验证 v0.2.2 覆盖升级、签名校验、数据保留、模型切换及工具续聊。源码与回环测试不等同于真实供应商、签名安装包和在线升级已验收。

# ShellPilot v0.2.4

本次更新新增 Kimi、Grok 和 Ollama 供应商，支持对话在后台继续运行、生成中选择下一轮模型，并加入 SSH 服务器资源监控与三套命名主题。

## 模型供应商与配置

- 新增 **Kimi / Moonshot** 独立入口，支持 Chat Completions 和 Messages，按协议提供思考开关及推理强度，保留工具续聊所需的思考内容与签名。Temperature 使用供应商默认值。
- 新增 **Grok / xAI** 独立入口，默认使用 Responses，也可选择 Chat Completions；支持推理强度、工具续聊与上下文整理。Grok Responses 的上下文用量采用本地估算，界面明确标识估算来源。
- 新增 **Ollama** 独立入口，使用 Chat Completions，支持本地或远程部署、查询已部署模型及一个渠道配置多个模型。默认地址为 `http://127.0.0.1:11434/v1`，默认无需 API Key，认证代理可自行开启。
- 新供应商沿用渠道搜索、供应商筛选、置顶及模型选择流程。已有 OpenAI 兼容渠道不会按域名或模型名称自动转换，需要时可手动选择对应供应商。
- 模型配置逐条检查：损坏或不受支持的配置单独提示，正常模型继续加载和使用；异常渠道暂停编辑，避免保存时丢失异常成员。真实数据库故障仍明确报错。

## 会话切换与上下文

- 回复生成期间可以切换历史会话或进入设置，原会话继续在后台运行；回复、工具执行、审批和停止操作绑定各自的会话。
- 离开会话后，后台任务成功结束显示蓝色未读点，异常失败显示感叹号，便于返回查看结果。
- 生成中可以编辑模型配置、调整推理强度或选择下一轮模型。本轮继续使用原配置，结束后应用新的模型选择；连续选择以最后一次为准，切换失败可重试或取消。
- 同一会话切换模型保留聊天记录、项目、SSH 目标及工具证据；包括同一 Ollama 渠道下 DeepSeek、Qwen 等模型之间的切换。旧模型专属思考、签名或密文不会跨绑定回放。
- 切换模型后保留上次上下文用量并标记“待更新”，下一次请求测量后替换，不再突然显示为零。旧统计仅供展示，不用于判断新模型的真实预算。

## SSH 服务器资源监控

- SSH 终端底部新增资源栏，显示 CPU、内存、上传和下载速度、运行时长及磁盘使用率；展开后可查看网卡、挂载点和上次开机时间。
- 支持手动刷新、暂停和继续监控，窄窗口与分屏自动适配。可见时每次采样完成约 5 秒后再次更新，隐藏或离开终端时暂停采集。
- CPU 和网速按两次采样的差值计算，首次短暂显示“采样中”；修复空行清空运行时间导致速率持续不显示的问题。上传为服务器发送，下载为服务器接收，无流量时显示 `0 B/s`。
- 首版支持 Linux / WSL SSH 主机，不需要 sudo 或安装远端组件。采集使用当前连接的独立只读通道，不向交互终端插入命令；暂时失败保留旧数据并自动重试。

## 主题与阅读体验

- 主题入口改为名称下拉框：**柔光白、暮雾灰、夜幕黑**。移除“跟随系统”，旧设置首次按当时系统明暗状态迁移为固定主题，之后不再随系统变化。
- 柔光白柔化终端及对话背景，暮雾灰使用灰蓝配色，新增夜幕黑使用近黑底色、炭灰面板和浅蓝高亮；三套主题分别保存文字颜色。
- 优化终端字体与暗色 ANSI 彩色高亮，增强目录、提示符和选中文字的区分度；修复终端底部白条及主题菜单点击被窗口拖动拦截的问题。
- 壁纸模式下代码块与标题栏采用半透明底色，默认不透明度分别为 65% 和 70%，跟随透明度设置并保留最低阅读底色。文字、语法高亮、复制及换行功能保持原样。
- 移除终端顶部重复的“展开对话”入口，保留现有动效和交互。

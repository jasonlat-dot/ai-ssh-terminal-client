# Agent 回复排版

主 Agent、子 Agent 和历史回复共用 `MarkdownMessage`，支持 GFM 表格、列表、代码高亮和 KaTeX 数学公式。
数学 CSS 与字体随客户端打包，不依赖在线 CDN。

支持的公式定界符：

- 行内：`$a^2+b^2=c^2$` 或 `\(a^2+b^2=c^2\)`。
- 块级：单独成行的 `$$` 围住公式，或 `\[ ... \]`。
- 数学代码围栏：`math` 语言围栏作为块级公式渲染。

LaTeX 括号仅在展示前规范化，不修改保存的回复、查看原文或复制内容。
普通代码围栏、行内代码、缩进代码与链接目标不作公式替换。
不完整的括号公式在流式生成期间等待闭合；无效公式显示可读的源码，不能导致回复区崩溃。
宽公式在自身区域横向滚动，不撑宽聊天面板；代码高亮仍只在生成结束且回复不超过 50000 字符时执行。

公式设置 `trust: false`，不允许公式命令插入任意 HTML、链接或网络图片；限制宏展开数与自定义尺寸。
原回复内的 HTML 仍不会执行。

相关官方说明：[remark-math 与 rehype-katex](https://github.com/remarkjs/remark-math)、
[KaTeX 配置](https://katex.org/docs/options.html)。

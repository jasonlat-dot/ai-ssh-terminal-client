# 服务器资源状态栏

SSH 终端底部显示 CPU、内存、上传／下载速度、运行时长及磁盘使用率，点击状态栏展开网卡、磁盘和上次开机时间。展开面板可暂停、继续或手动刷新。亮色、暗色及壁纸模式沿用当前主题，窄窗口和分屏自动换行，必要时可横向滚动状态栏。

目前支持 Linux／WSL 服务器；本地 CMD 不显示，其他环境显示不支持或采集不可用提示。监控复用当前终端认证后的 SSH 连接，在独立 exec 通道执行固定只读探针，不需要 sudo、不安装远端组件，也不会向交互 Shell 写入命令或聊天上下文。

- 可见终端每次采样完成后等待 5 秒再采样；离开终端、窗口隐藏或手动暂停时取消请求。恢复后立即采样。
- CPU 和网速用两次读取的累计值之差计算，首次显示 `—`／“采样中”，正常约 5 秒后显示数值；网速为这段时间内的平均速度，测得无流量时显示 `0 B/s`。网络单位为 B/s、KiB/s 等，↑ 是服务器发送，↓ 是服务器接收。摘要优先显示默认路由网卡，详情列出各非回环网卡。
- 内存按系统可用内存计算，避免把可回收缓存全部计入占用。磁盘摘要优先根文件系统，详情列出可读的本地挂载点；运行时长及开机时间来自服务器。
- 失败保留上次数据并标记“旧数据”，15 秒后重试；未知值不显示成 0。重连和其他终端使用独立缓存，迟到响应不能覆盖当前终端。

桌面通过 `GET ssh/terminal/resources` 的原生 IPC 分发到 Rust TerminalManager。此功能修改了内置 Rust 后端，需要重新编译并启动桌面应用，单独刷新前端不能加载新增接口。详细口径及限制见 [后端说明](../../ai-ssh-terminal-server-rust/docs/TERMINAL_RESOURCES.md)。

# 操作结果提示

保存、添加、修改、删除、恢复等操作使用全局顶部浮动提示，不在页面内保留成功提示条。成功后才提示成功；失败时保留表单或草稿。字段校验、加载状态、连接状态、工具输出和传输进度继续在原位置显示，删除前继续确认。

提示通过 `src/state/notifications.ts` 的 `notify(message, type, durationMs)` 发布，根 App 的 NotificationCenter 统一渲染到 document.body。工作区、设置页、独立设置页和配置弹窗共用入口，不因切换页面或工作区重新初始化而消失。成功 / 信息默认 3.5 秒，错误默认 6 秒，已有连接进度可指定持续时间。最多同时显示四条，相同内容与类型的提示合并并重置计时；悬停、键盘聚焦和查看错误详情时暂停自动关闭，支持手动关闭和读屏播报，尊重减少动态效果设置。

接入范围：

- 模型保存与删除；删除改为确认弹窗。
- 执行额度与子任务开关、MCP 和 Skills 各自保存；恢复推荐值提示尚需保存。
- SSH 连接添加、修改、删除；保存并连接时不重复显示保存提示。
- 项目创建、对话标题修改；沿用对话删除和项目移除的成功提示。
- 长期记忆添加、修改、删除、启用与停用。
- 常用命令保存、终端命令批量提交，以及既有复制和文件删除等通知。
- 工作区配置保存、自动初始化开关和初始化 / 停止操作。
- 壁纸保存、还原、移除，透明度与文字保护，以及字体、字重和文字颜色自动保存 / 恢复。

原模型成功条、工作区成功条、工具设置页保存结果和命令广播结果已移除，相应闲置样式清理。MCP / Skills 的分区保存行为保持不变。

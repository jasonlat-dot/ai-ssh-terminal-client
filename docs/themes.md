# 界面主题

顶部通过主题名称下拉框切换，支持键盘操作：

- **柔光白**：现有浅色主题，柔和灰白背景与低饱和蓝色。
- **暮雾灰**：现有暗色主题，灰蓝底色与柔和文字。
- **夜幕黑**：参考 `ai-shell-floating-night.html` 的颜色，使用近黑底色、炭灰面板和浅蓝高亮；同步覆盖终端 ANSI 配色、对话区、设置页和启动页。

主题选择自动保存在本机，重启后恢复。已移除“跟随系统”：旧设置为跟随系统时，首次启动按当时的系统明暗状态迁移为柔光白或暮雾灰，之后固定使用该主题。首次安装默认柔光白。

三套主题分别保存主要、辅助文字颜色，恢复当前主题的默认颜色不会清除其他主题的设置。旧版保存的浅色与暗色文字颜色继续有效。

新主题只调整颜色，沿用现有布局、动画、终端字体与壁纸交互。切换主题更新当前终端的配色，不重建终端连接。

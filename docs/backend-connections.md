# 应用工作区与终端

Rust Preview 的当前架构只有应用内工作区。已移除远程后端地址、连接档案切换、后端证书和 HTTP 连接测试。SSH 配置中的服务器地址/端口仍是目标 SSH 服务器，不是另一个 ShellPilot 后端。

SSH、SFTP、附件和历史管理通过 IPC 调用同进程 Rust 功能。安装版无需本地 HTTP 监听端口。设置页只管理本地数据目录、自动初始化和附件存储策略；重新初始化会断开 SSH/SFTP，但不会删除数据库和附件。

旧远程后端配置不再生效，应用不会自动连接旧地址。后续 Agent 在本地 Rust 运行，通过模型服务 API 发送请求；当前 AI 界面仍未启用。

下面的终端和外观功能说明沿用原有行为；AI 附件/对话相关内容为后续迁移参考，不表示当前 Rust Preview 已开放。

## 终端排序与分屏

整张页签（关闭按钮除外）可左右拖动排序，拖动时有跟随预览和插入位置标记，松手后应用；Esc、失焦或取消拖动保持原顺序。键盘可使用 Ctrl+Shift+左右方向键。
排序只调整页签，不关闭或重建本地 CMD / SSH 会话；可恢复的 SSH 页签按调整后的顺序保存。
终端页签右侧「布局」提供单窗口、左右分屏、上下分屏与网格分屏（最多四窗）。
分屏默认加入当前终端和其他已有页签；各窗格顶部下拉可指定终端，选择另一个已显示终端时交换位置，不重复显示同一会话。
布局和窗格选择均使用主题适配的自定义浮层，下拉有选中标记、悬停高亮及键盘导航，不使用浏览器原生灰底菜单。
点击某窗格激活它，默认情况下常用命令与 Agent 的终端上下文跟随活动窗格；点击未显示页签会替换当前活动窗格。
关闭页签后自动补入其他已有终端，少于两个页签时禁止开启新的分屏；窗格「单窗口」按钮返回当前终端。
切换布局和排序保留已有终端视图、输出和运行时，只调整显示与终端行列尺寸，不重新连接。

## 手工与常用命令广播

终端工具栏下方的「命令目标」默认是「当前终端」，可切换为「全部终端」或「勾选终端」。
「全部终端」包含未显示的已连接页签；「勾选终端」只发送至明确勾选且连接可用的会话，空选区不会退回当前或全部。
广播模式显示独立命令输入条：手工输入后按 Enter 或点击执行按钮，同一命令并行提交至目标终端。
长命令自动折行、输入区随内容和宽度增高，最高 160px（不超过窗口高度的四分之一），超过后在输入区内滚动，不遮住终端。
自动折行不会增加命令换行；Shift+Enter 可主动换行，Enter 提交完整内容。中文输入法确认和长按 Enter 不触发重复提交。
点击常用命令名称只填入广播草稿，不直接执行；点击「运行」使用相同目标提交。提交期间禁用再次提交与目标调整。
普通终端中的键盘输入、粘贴、密码、补全及交互操作仍然只发送至当前终端，不广播。
Agent 始终只绑定发送请求时的活动 SSH 终端，广播范围不会扩散 Agent 的上下文或执行目标。

断开、关闭、忙碌或运行时已变化的目标会跳过；每次提交锁定具体运行时，重连不会把旧命令发送给新会话。
界面报告已提交的数量和未成功目标，但「已提交」不代表命令执行完成，请查看各终端输出。
正常提交只显示输入条下方的状态，不弹成功通知；失败或跳过目标仍弹错误提醒。「Agent 始终单终端」使用主题蓝色徽标高亮。
部分失败不自动重试、不回滚；失败时保留输入草稿，手工重试前请检查已经提交的终端，避免重复执行。
广播范围与选区不持久化，应用重启或重新初始化工作区后恢复单终端模式。

## 终端选区与粘贴文本

本地 CMD 与 SSH 终端选中文本后会出现「添加到对话」浮动入口，工具栏也提供相同按钮。
添加会展开智能体对话栏，只加入草稿，不执行命令或自动发送；保留原来输入的问题。
少于 100 个 Unicode 字符直接显示在输入框；100 字符及以上转为可移除的文本卡片。
在对话框粘贴文本也遵循同一规则，短文本保留原生光标/选区粘贴行为。

长文本保留完整换行、空白及 UTF-8 内容，作为 TXT 附件上传；卡片只显示紧凑摘要、来源、字符数及准备状态。
与普通附件共用每条最多 4 个、合计最多 20 MB 的限制；文本与文件混合粘贴会一起校验，超限不部分加入。
上传中或失败时不能发送，可重试或移除；失败保留草稿，发送成功才清空。
历史消息保留卡片摘要，恢复请求/再次附加复用文件 ID；实际发送完整附件，不用摘要代替正文。

## 客户端外观与本地壁纸

「界面字体」可选择常用本机字体或输入已安装的字体名称，并独立设置正常/粗体字重（100–1000 整数）。
设置实时生效、仅在客户端自动保存，重启保留；字体未安装或不支持某个字重时使用可用的替代效果。
「恢复默认字体与粗细」不影响自定义文字颜色或壁纸。终端输出、代码块、PEM 等等宽输入与公式仍使用原字体规则。

常用命令与智能体对话面板的左边界均可左右拖动；向右缩到最小宽度以下自动收起。
通过终端工具栏对应按钮重新展开，会恢复本次运行中最后的有效宽度，不结束终端会话或中断智能体对话。
边界支持方向键微调、Home/End 调至最小/最大、双击恢复默认宽度。

在「设置 → 外观」选择本地 PNG、JPG、GIF 或 WebP 图片（包含动态 WebP），最大 10 MB，单边不超过
8192 像素且总像素不超过 3200 万。也支持 MP4 视频，最大 100 MB，最长边不超过 3840 像素且总像素不超过 4K。
MP4 容器不保证编码兼容：客户端先验证实际解码能力，推荐 H.264 编码，无法解码时明确提示且保留旧壁纸。
选图后直接在工作区效果预览中拖动调整位置，
缩放 100–400%，选择当前窗口、16:9、16:10、4:3 或 1:1 比例。
预览按客户端窗口比例展示，不显示裁剪辅助网格；固定比例决定壁纸选区而非整个预览窗口的形状。
预览只显示壁纸与透明度效果，不叠加模拟工具栏、侧栏、图标、光标或文字；状态仍保留供读屏软件读取。
也支持方向键移动、Shift 加速、+/- 缩放、Home 重置；拖动不会露出图外空白。
点击「应用此区域」才保存并替换当前壁纸；取消保留旧壁纸，原文件不被修改。
同时保存原图、上次选区与显示用的裁剪图片；裁剪图最长边最多 3840 像素且不放大小图。
GIF/动态 WebP 和 MP4 不通过 Canvas 导出静态帧或重新编码：保留原文件，另存比例、缩放、位置和显示方式，
预览与全局背景使用同一选区几何显示动画。视频默认静音循环，没有音频或播放器控件；右侧缩略视频只显示帧，不播放。
窗口最小化/不可见或预览滚出可见范围时暂停视频，恢复可见后继续；普通失焦不会暂停，录屏工具获得焦点时仍可播放。
播放由事件驱动，不增加轮询；替换/恢复默认/卸载时释放播放器、监听与 Blob URL，不重建 SSH/Agent 工作区。
应用后外观页一直显示工作区效果预览、比例、缩放与显示方式，不再需要点击「重新裁剪」进入编辑。
打开外观页会恢复上次比例、位置和缩放，可以直接反复调整，无需重新上传，重启后仍能编辑。
调整即时体现于工作区效果预览，点击「保存画面」才替换全局壁纸；保存后控件仍在原位，不退出编辑。
「还原已保存画面」丢弃未保存调整，不写库；保存失败保留当前壁纸与可重试的原图草稿。
即使窗口尺寸变化，也保留上次实际比例，可另外选择「当前窗口」。
每次导出都基于原图，不在上次裁剪结果上反复压缩；取消更换图片不会改变已显示的壁纸。
旧版本只保存了裁剪图时也可继续裁剪，但会提示无法恢复已裁掉的区域；重新选择一次原图后即可完整编辑。
图片不上传到后端。「裁剪比例」决定保存哪些内容，「壁纸显示方式」决定如何适配窗口：

- **铺满窗口**：保持图片比例填满窗口，比例不同时裁掉部分边缘。选择当前窗口裁剪时默认使用。
- **完整显示**：完整保留选区和比例，不拉伸、不裁边；剩余区域显示主题底色。
  选择 1:1 等固定裁剪比例时默认使用，所以方形图片不会再次变成横向铺满。

裁剪时和应用后都可直接选择显示方式，确认保存画面后随当前图片一起写入 IndexedDB，重启后保持。
旧壁纸未保存显示方式时继续默认铺满；已有方形壁纸可直接选「完整显示」并保存，无需再次导入。

外观页居中限宽 1280px，桌面宽屏采用左侧工作区效果预览、右侧 380px 壁纸设置的布局，保存与还原操作放在顶部标题栏。
预览保留实际客户端窗口比例，宽度最多 900px、高度最多 500px，不随页面剩余高度拉伸。
取消额外的底部操作提示、文件信息栏与顶部「已保存」状态；左右等高的小标题使预览画面与原图更换入口的上边缘对齐，不用额外补偿间距。
右侧「更换壁纸」入口使用原图作铺满式缩略背景，叠加轻蒙版，弱化底部文字与上传图标，悬停/聚焦时增强提示；整个缩略图可点击更换。
删除图标仍独立叠在图片底部，不出现两侧主题留白或独立盒装按钮。
入口缩略图适配时可能裁掉装饰性边缘，但不修改原图、左侧选区或保存内容，也不受草稿比例、缩放或透明度影响；
其下依次显示画面比例、缩放、透明度、显示方式与文字保护，不增加背景库或工作区列表。
界面文字颜色与字体设置独立放在预览下方，宽屏并排、窄屏堆叠，自动保存逻辑不变；更换壁纸不会重建文字设置输入区。
外观分组和控件使用与其他设置页一致的图标及轻量徽标；比例和显示方式保留选中边框、勾选和随透明度变化的高亮底色。纯壁纸预览内不添加装饰图标。
字体选择位于「界面字体」标题后，与左侧颜色设置标题对齐；采用主题下拉浮层，提供选中勾选、悬停、聚焦与键盘选择，不再使用操作系统的白底原生菜单。
原图缩略图叠加 18%–34% 的轻蒙版，只影响更换入口，不影响实际壁纸；下方显示支持 PNG / JPG / GIF / WebP / MP4，播放规则保留为悬停说明。
壁纸显示方式使用简短提示，悬停可查看完整说明，读屏说明保持完整。
窄窗口自动改为上下布局。仅外观页隐藏可见滚动条，
小窗口仍可通过滚轮、触摸和键盘访问全部控件，不裁掉保存按钮或错误提示。

「背景透明度」为 0–100%，默认 25%。数值越大壁纸越明显，整张工作区使用一层主题遮罩，
包括标签栏空白和面板间距；命令卡片、分类、连接列表、聊天输入区等内部底色不再重复铺设。
设置页的输入框、下拉选择触发器、证书导入区，以及模型/存储等分区的卡片同步适配。
展开的下拉选项通过独立浮层显示，仍保留正常主题底色，避免与壁纸和后方控件混在一起。
文字、图标及状态点不变淡；选中项保留边框与标记，浮层仍保留独立底色便于阅读。
终端底色同步适配，不重建 SSH 会话。浅色、深色主题均可使用。
「文字可读性保护」默认开启：高透明度时加强辅助文字和状态文字的对比，壁纸逐渐柔化
（只处理底层图片，最高 4px，不模糊文字）。整张工作区保留统一遮罩，浅色至少 65%，
深色至少 70%；这意味着滑块 100% 代表保护模式下壁纸最明显，并非完全无遮罩。
关闭保护可恢复完全透明的原图效果，但复杂或明暗反差大的壁纸仍可能干扰阅读。
该开关独立保存在 localStorage（`agent-ssh-wallpaper-readability-v1`），恢复默认背景不重置它。
透明度与可读性保护即时生效并自动保存；比例、缩放、位置和显示方式在预览后确认保存。
「恢复默认背景」移除壁纸并恢复默认透明度，不改变主题或连接。

原图和裁剪图以 Blob 保存在当前客户端 WebView 的 IndexedDB（`agent-ssh-appearance`），
两张图片和选区在同一条记录中原子替换；空间不足时全部保留旧版本，恢复默认则一起删除。
动态图/视频仅保存原媒体与选区（显示与原文件共用 Blob）；重新打开后恢复动画/视频、显示方式与取景，不需要重新上传。
透明度保存在 localStorage（`agent-ssh-panel-transparency-v1`）。关闭、重开客户端后复用，
原图片移动或删除不影响已保存壁纸。清除 WebView 数据则会清除这些偏好；
普通浏览器与桌面客户端各自保存，开发模式与安装版也可能使用不同的 WebView 数据空间。
外观不写后端 YAML，不跟随后端统一数据目录迁移，切换内置/远程连接不会覆盖它。
导入、解码或存储失败时保留旧壁纸并显示错误，不会谎报保存成功。

「界面文字颜色」支持主要文字与辅助文字两项，可使用颜色选择器或输入 `#RGB` / `#RRGGBB`。
六位 HEX 与选择器实时生效、自动保存；三位简写在失焦或按 Enter 时保存，无效值提示错误且不应用。
当前浅色、深色主题独立保存，跟随系统时按实际主题应用。恢复当前主题文字颜色只清除该主题覆盖，
另一主题、壁纸、透明度和终端配色不变。即使没有壁纸也可设置；恢复默认壁纸不清除文字偏好。
普通界面标题、正文、输入框和辅助说明使用新颜色；终端输出/ANSI、Markdown 代码/语法高亮、
状态提示与实心按钮保留原配色。偏好仅保存在客户端 localStorage（`agent-ssh-ui-text-colors-v1`），
重启后恢复，不上传到后端。存储失败时保留原配色并提示，损坏的值自动回退主题默认。

## 连接设置概览

在「设置 → 连接」管理客户端连接与本机后端。两者分开保存：

- 「客户端连接」保存连接名称、根地址和公开证书信任设置，不写 Java/Nginx 配置。
- 「内置后端 HTTPS」与端口、数据目录等设置只写本机外置 application*.yml。
- 内置配置保存后不会自动切换当前连接，也不自动重启；重启本机服务后生效。
- 下拉框只选择查看/编辑对象，顶部始终显示真正使用的连接。选择其他档案时提示「已选择，尚未使用」，
  必须点击「使用此连接」或「切回内置后端」才会切换。底部保存结果明确说明当前连接未改变，
  不代表上方远程连接已保存或应用；底部未保存状态也只统计内置后端 YAML。
- 各设置分区显示「暂无未保存修改」时，底部保存按钮灰显且禁用。修改后启用，重置或保存成功后再次禁用；
  保存中也禁用，处理函数同时拦截无修改的提交，避免无意义写入。

## 使用内置后端

HTTPS 证书模式默认选择「自动管理本机自签证书」。对应 `server.ssl.enabled=true`、
`server.ssl.auto-generate=true`。默认证书仍在统一数据目录/tls，密码由后端自动读取，
不用手工填写。有效证书复用，临近过期时更新，已有 TLS 文件不需删除。

Java 的 HTTPS 不能关闭，界面不再提供 HTTP 模式；远程 Nginx/Caddy 到 Java 的上游也必须
使用 HTTPS。旧外置 YAML 若设置了 `server.ssl.enabled: false`，需改为 `true` 并移除
关闭 SSL 的环境变量或命令行覆盖，否则拒绝启动。客户端不自动改写这些旧配置。

选择「自定义证书库」时填写本机 PKCS12/JKS 路径、类型、密码和可选别名。
仅设置本机 Java 的服务端证书，不接受远程 Linux 路径。密码不回显，留空保留已有配置；
非空密码会写入本机后端配置文件及其备份，应保护配置目录权限，不分享这些文件。
自定义证书须由系统信任，默认自签证书例外不会自动套用到另一份自定义证书。

「保存内置后端配置」后重启本机服务。连接档案选择「内置后端」并点击「切回内置后端」，
会按需启动本机 Java，并采用实际协议/端口。不会删除远程档案或改变自动启动偏好。

内置服务状态采用「先订阅事件，再读取一次快照」：Rust 只在 starting/running/failed/stopped
或说明、地址等发生变化时发送 `bundled-backend-status-changed`，前端根据递增 revision
忽略旧结果，关闭页面后取消订阅。启动页不再每 400ms 查询，设置页不再每 1.5s 查询。
Windows 在独立后台线程等待 Java 进程退出的系统信号，意外退出时通知前端；正常停止和
重启不会被误判为失败。其他平台采用每 2 秒一次的本地子进程检查，不请求 Java 或 WebView。
开发模式中不是由客户端创建的 IDEA/远程 Java 不纳入进程监视。
进程状态不代替 `/api/health`：HTTP 健康检查仍使用原有手动检查及可配置的自动刷新。

## 连接远程 Java 或 Nginx

点击「新增远程连接」，填写名称及根地址，如 `https://ssh.example.com`。
不要填写 /agent、/api/v1/ssh 或 Nginx 后面不对外开放的内部端口。

正式公网证书选「系统信任」，不需要导入证书。服务器私钥、key-store 密码和 /etc/ssl
配置留在服务器，不应复制到客户端；此界面不申请、部署或续期远程证书。
远程后端的 HTTP/2 由远程 Java/Nginx 决定，与本机 HTTP/2 开关无关。

终端读取已移除全局 6 个并发名额及前后台排队，各终端独立长轮询；保留单终端
防重入、请求取消和失败退避。需在 WebView 开发者工具中确认 terminal/read 的 Protocol
为 h2；独立原生连接测试不证明 WebView 使用了 HTTP/2。若实际仍是 HTTP/1.1，
浏览器连接限制仍存在，多个长轮询可能占满连接槽；此版本不再通过前端队列预留名额。

Windows Tauri 桌面支持「指定服务器自签证书」：从可信渠道导入单张 PEM 服务器公开证书，
不导入 PRIVATE KEY、.p12 或 CA/完整证书链。可以先独立测试，确认后再保存或使用连接。
WebView2 仅在活动连接地址匹配、服务器证书内容完全一致且有效时允许 CA 信任错误；
主机名不符、过期等仍拒绝。此模式不跟随 HTTP 重定向，需要填写最终 HTTPS 地址。
原生文件传输加载同一连接的公开证书，继续验证主机名和有效期。
普通浏览器及其他平台目前使用系统信任，不提供全局忽略证书错误开关。

「保存连接」只保存非活动档案，不切换当前连接；编辑活动档案时按钮明确显示「保存并使用」。
「使用此连接」才激活相应档案。桌面版「测试连接」使用每次新建的原生 HTTP/TLS 客户端，
直接使用页面草稿中的地址和验证方式，不要求先保存或激活，不复用 WebView 的证书允许缓存，
也不更改当前活动连接、本机证书身份、cookie 或系统证书库。
系统信任只读取操作系统根证书，远程 localhost/127.0.0.1 也不会自动信任内置证书。
指定证书只补充本次草稿提供的公开 PEM，主机名、有效期和签名仍须通过校验。
内置档案测试可读取其端口已登记的本机公开证书快照；该例外不提供给远程草稿。
独立测试最多 4 秒，只请求 /api/health，拒绝重定向，并限制响应长度。
失败时除说明原因，还展示已收到的 HTTP 状态及响应正文摘要；错误正文只读取前 8 KiB，
摘要最多 2048 字符（另附截断标记），PEM 内容不回显，不保存到连接档案或普通日志。
摘要以纯文本呈现，即使返回 HTML 也不会作为网页执行。TLS 握手/网络失败没有 HTTP 正文时不显示摘要。
HTTP 请求打到 HTTPS 端口且返回 Tomcat 的 requires TLS 提示时，直接提示改用 https://，
同时保留正文摘要便于排查。独立原生请求仍不出现在 WebView 的 F12 Network 中。
它确认传输和基础存活，不替代 WebView CORS、业务登录或权限检查。
普通浏览器仍使用浏览器原生请求，不提供桌面版指定证书测试能力。
无法删除内置连接或正在使用的远程连接；切换后可删除闲置远程档案。

切换时清除旧 WebView 证书允许缓存，并重建工作区，关闭旧终端轮询、聊天流和文件传输。
URL 相同但证书档案不同也会重建工作区。按后端 URL 保存的本机会话缓存保留，
同一 URL 的不同档案仍指向同一个后端地址空间，不复制服务端数据。

旧版单地址设置自动兼容为内置或远程档案。选择远程后，客户端不等待本机 Java 启动；
是否自动启动本机服务仍由原有开关单独控制。远程连接失败不回退到本机，以免误操作其他数据。

注意：TLS 只解决传输安全及服务器身份，不替代 API 登录/鉴权、权限隔离或 CORS。
本次没有新增远程 Bearer 登录或客户端双向 TLS 功能；当前服务的鉴权方式保持原样。
新功能涉及 Rust 桌面壳和默认后端配置，开发版需重启 Tauri，安装版需重新打包。

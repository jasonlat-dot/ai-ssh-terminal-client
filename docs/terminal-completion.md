# 终端补全

当前实现支持 SSH Bash 4.4+ 的 emacs 单行末尾补全。路径与本次手动命令历史在应用内匹配；AI 续写是独立可选增强，不自动读取文件正文、配置或脚本，不提供让模型请求文件的工具。

## 开启与使用

1. 本轮涉及 Rust / Tauri IPC，需完全退出托盘中的开发应用后重新运行 `npm run tauri dev`，仅刷新页面不能加载原生变更。
2. 模型设置顶部打开“终端智能补全”。仅使用路径和历史候选时无需选择模型。
3. 新建或重连 SSH 会话会自动安装会话级 Bash 集成；已有会话不自动注入，重连后生效。顶部“终端 → 重新接入 Bash 补全”保留为手动重试入口，必须先回到空 Bash 提示符。
4. 如需云端续写，再打开“AI 续写”并选择已有可用模型。“向 AI 提供当前目录”独立控制，默认关闭。
5. 停止输入默认 500ms 后显示灰字；按 → 填入后缀，Esc 隐藏，Tab 保留远端补全。接受后仍需自己回车执行。

自动接入仅发生在新 SSH Shell 创建阶段、用户输入前。配置了自定义 `startup_command` 的连接跳过自动安装，避免干扰 sudo / 跳板 / 自动启动程序，可在最终 Bash 提示符处手动接入。不支持的 Shell / vi 编辑模式明确返回未接入，不强制更换 Shell。集成只影响当前 Shell，不修改 .bashrc，不写远端脚本文件；短加载命令仍可能进入 Bash 自身历史。关闭总开关会停止候选查询与模型请求，钩子保留至 Shell 退出。

## 数据边界与候选顺序

- 本次终端中手动回车执行的命令最多保留 100 条，仅驻留内存；不会读取 .bash_history、磁盘历史、AI 对话或整屏内容，销毁终端即清除。AI 执行回执不会自动成为候选。明显凭据参数会跳过，但过滤不是完整脱敏，不能保证识别所有秘密。
- 优先匹配本次手动历史，再匹配路径。路径查询使用原 SSH 认证连接开独立 SFTP 通道，只调用目录枚举，不读取文件正文、不执行 Shell、不自动 sudo。目录候选不发给模型，最多 256 项；应用内最多 8 个目录缓存，每项 3 秒。多个匹配优先显示公共前缀，Tab 仍可在远端查看其他候选。权限不足、SFTP 不可用或目录过大时可能没有路径建议；sudo 后的 Shell 身份不用于自动提升 SFTP 权限。
- 路径支持常见文件命令、显式绝对/相对路径、家目录、父目录、目录筛选与空格/引号转义；复杂 Shell 表达式、变量展开、远端主机路径不做猜测。路径查询失败时，不把目录候选交给 AI 兜底。
- 本地没有可用候选且开启 AI 续写时，独立无工具请求只包含当前输入和固定 shell=bash；仅当“向 AI 提供当前目录”开启时才附带 cwd。历史不作为附加上下文上传，目录清单、文件正文不进入 AI 上下文，也不进入补全 Trace 正文。手动调出或接受历史后，它成为当前输入，后续输入触发 AI 时也遵守当前输入的发送设置。当前输入本身可能包含敏感信息，应选择合适的模型服务；简单过滤不等于保证不泄露。
- AI 上下文与聊天独立，模型 Key 由 Rust 从已有配置读取，不保存在补全偏好中。不自动使用真实凭据做诊断请求。

## 稳定性

Bash 私有 nonce / 提示符 / 执行标记与 Readline 快照读取真实 READLINE_LINE / POINT、PWD 和 HOME；光标位于中间、折行、备用缓冲区、输入法组合、选区、失焦、隐藏或断线时暂停建议，不根据屏幕猜完整输入。

Readline 快照重绘使用 xterm 公共同步输出模式合并，返回后等待短暂输出稳定再释放，最长 1.3 秒自动释放。继续输入与灰字一致时，保留剩余建议并在实际回显后重定位，不清空重请求；输入不匹配、光标实际移动或上下文变化时撤销。

初始化静默读取最多 10 秒，手动初始化前端 12 秒未确认提示重试；SSH 自动安装仍受连接配置的超时限制，失败不会自动重放脚本。输入查询 1.2 秒无回执停止探测。SFTP 查询总期限 1.5 秒，原生请求取消/关闭终端后释放通道。

AI 请求继续限制两秒总模型期限、64 输出 tokens、64 KiB 响应和最多四并发；返回最多 256 bytes 单行后缀，拒绝控制字符、代码围栏、截断响应。客户端候选流程总期限四秒，输入变化立即取消，旧回执不能覆盖新输入；不自动执行建议。

## 自动接入加载命令回显修正（2026-10-21）

自动接入的新 SSH PTY 从创建时关闭输入回显，完整载荷静默读取结束后执行 stty echo；服务端确认回显已恢复才发布终端。成功安装标记 I 本身不再代表可以立即开放输入。不支持的 Shell 同样先恢复回显；恢复失败或等待超时关闭本次连接，不向同一终端自动重发脚本。正常登录输出保留，不通过清屏隐藏加载命令。

此修改只用于启用自动补全、没有自定义启动命令的新连接；普通连接和自定义启动流程不改变 PTY 模式。手动“重新接入 Bash 补全”仍可能显示一条短加载命令，完整脚本不应显示。4 项回环 SSH 协议/模式/恢复时序测试通过，真实 SSH 视觉仍需更新开发应用并重连后验收，旧终端已有文字不会被删除。


## 路径候选重复修正（2026-10-21）

文件名完整输入后再加空格，会开始补全下一个参数。此前没有排除已输入的文件，目录只有一个匹配时，会出现 `cat get-docker.sh get-docker.sh` 的重复灰字。现在 `terminalCompletionLocal.ts` 在计算公共前缀之前排除已有路径参数；相对/绝对/家目录及带空格的参数按当前目录做字符串归一化，不解析符号链接，不读取文件正文。

首次 `cat ` 仍可推荐文件，后续不同文件仍可补全；只抑制自动路径候选，不限制用户手动重复参数。无剩余路径候选时仍不向 AI 兜底。新增 3 项回归先复现失败、修复后通过，覆盖完整文件、尾随空格、接受后缀/远端 Tab 后的快照、不同路径写法和缓存目录；前端相关 62 项测试、TypeScript、Vite 资源构建通过（保留既有大资源块提示）。本轮未改 Rust 生产代码、未打包，真实 SSH 视觉尚待用户确认。
